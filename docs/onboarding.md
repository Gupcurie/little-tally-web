# Daily role selection and tutorials

Signed-in users choose from nine options on their first visit each Beijing day: angel/devil × beginner/experienced × dismantle/place, plus keep the previously active ledger. New users have a personal ledger; existing users keep the selected custom group or personal ledger when choosing the ninth option. Account 123 sees the selector every page load. Version-1 profiles are prompted once to upgrade to version 2.

Angel/devil options join today's corresponding shared room. Beginners receive an eight-step job-specific tutorial; experienced users enter directly. A confirmed role switch reloads permissions. Daily-room permissions come from database membership, not Auth metadata. Dismantle enables sales/stock and blocks egg edits/future recommendations; placement enables egg and can separately enable its independent, initially hidden inventory count. Both see daily matching and candidate time ranges. Outside daily rooms, previous feature preferences are restored and ordinary group permissions remain unchanged.

The ninth option changes no workspace, quantities or feature switches. Settings can reopen the current job tutorial. Original six-step standalone tutorials remain available outside daily rooms. Both tutorial endings include Settings replay and the user-supplied WeChat L2385434375/SMS 13480041761.

Authenticated Auth metadata tally_onboarding is display preference only: version, day, role, books, tutorialPending, updatedAt, optional roomKind/outsideBooks/outsideRole. A per-account local mirror is used. No preferences grant permissions. Manual optional placement-stock enablement is stored in the authenticated daily membership, defaults off, and never links to sales or placements.

See daily-rooms.md for permission/read/write contracts and daily-reconciliation.md for the order-independent comparison algorithm.
