# 组队、分段、多蛋购买与网络安全（2026-11-05）

## 使用规则

- 顶部“切换 / 组队”支持个人账本和已加入群账本。创建群使用名称和自定四位数字；登录后才能创建/加入。入群码按北京时间创建当天23:59失效，不退出已有成员。同一天号码不能重复，错误尝试受账号和IP共同限制。创建空群只沿用品类，不转移个人数量或历史。明确切回个人后记住个人选择；加入/创建会切到群。群成员每5秒读取更新，并以修订号保护同时保存，冲突会读取新版本而不覆盖。
- 放蛋顶部“查看总数”显示累计；复制菜单可选择本轮进度（包含超出）或累计总数。
- 多蛋购买自选1–10件，暂存不改任何数量；确认时作为一笔云端事务保存。销售库存绑定开启时共同验证、共同保存。历史同组使用随机颜色框；取消不写记录，未确认时禁止跨个人/群或切账本。
- 跨天不自动清零。“设置→开启新的一天”结算当前销售/库存/放蛋三本，开启全零新段，保留品类和比例。可按北京时间日期范围或直接勾选旧段/本次即将结算段，选择继承哪些账本；所选各段最终数量相加。库存分项也相加。旧段在独立归档表保留完整记录，日历可读；新段继承是起始数量，不重放销售联动。结算有幂等重试和修订冲突保护。
- 销售/库存统计增加横轴时间刻度、纵轴单位/最大值；分钟视图的0–23小时滑块选择时段，拖动后更新该小时60分钟。堆叠总量决定最大刻度，不会因多物品叠加溢出。

## 云端权限

数据库表全部位于不对客户端开放的tally_private，启用RLS并撤销anon/authenticated直接表权限。公开RPC只向authenticated授予执行，内部检查auth.uid与群成员关系；管理员只读群与安全接口仅service_role可执行。个人仍走原tally_save和用户RLS，群独立team_ledgers/team_backups，群缓存也与个人分开。切换先清页面草稿/推荐缓存，再读取目标命名空间，迟到请求不能覆盖新命名空间。

数据库权限设计参考[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)和[数据库函数权限](https://supabase.com/docs/guides/database/functions)。四位码空间有限，登录、限速和成员检查降低猜码风险，不能承诺绝不会被猜中；不要公开传播号码。

## 安全记录与防御范围

公网nginx设置请求/连接频率限制、登录限速和超时，保留TLS和现有CSP；可信边缘覆盖转发IP。此为应用层防御，不是运营商级流量清洗。安全服务只监听本机文件，不开网络端口、不暴露Docker socket给后台。

nginx仅记录时间、真实来源IP、方法、路径和状态，不记密码、Authorization、Cookie、请求体或查询参数。主机tally-security服务每3秒采集被拒绝/限速/错误/敏感路径请求，归档错误入群码和数据库敏感删除/恢复/结算操作。合法后台导出标为管理操作。记录不能证明攻击成功，也不能保证发现所有数据外泄。

默认不封IP。管理员在后台“网络安全”查看并手动封禁/解除；当前连接和服务器回环地址不能封，IP严格解析，不能注入命令。请求写入/data/ip-blocks.json，主机服务检验地址后生成独立nginx deny文件，nginx -t通过才reload。安全面板显示服务心跳，超过30秒会提示失联。

日志和配置位于/opt/little-tally/admin/data/network及/opt/little-tally/security，均不在网站静态目录。事件轮转有容量上限，UI展示最近300条；旧日志保留有限文件，不是无限审计存储。四文件compose基础链的docker-compose.ip-test.yml也包含日志和安全配置挂载，避免未来重建丢失。
